## What Is AoC Script Studio?

AoC Script Studio provides a dedicated browser workspace for composing Age of Conan chat scripts. The application is packaged as one HTML file and operates offline, allowing it to be used locally without a backend or an active network connection after it has been opened.

The editor is intended for players and script creators who want to prepare formatted chat messages, design visual banners, and produce output that can be shared. Its streamlined workflow handles markup-oriented content while providing formats appropriate for in-game use.

## Included Capabilities

- Compose Age of Conan chat scripts in a web browser
- Run the complete application offline from one HTML file
- Use `font`, `img`, and `br` markup
- Design ASCII banners for decorative text arrangements
- Put together icon mosaics for compact visual layouts
- Save scripts as regular `.txt` files
- Produce `text://` links for sharing or reuse
- Work locally without setting up a server during installation
